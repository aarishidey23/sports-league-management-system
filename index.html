Academic project guide

SportSphere was engineered specifically for a second-year Computer Science student project presentation.


📁 File Structure Blueprint:

sports-management-system/
├── index.html        (Combined single-page or landing)
├── login.html        (Simulated user authentication)
├── register.html     (Player/coach onboarding)
├── dashboard.html    (Main command center)
├── css/
│   └── style.css     (Modern Gen-Z Navy & Electric Blue CSS)
└── js/
    ├── data.js       (Sample datasets & default models)
    ├── auth.js       (LocalStorage authentication logic)
    └── dashboard.js  (Events, registration, filtering)

🚀 How to Run in VS Code:

  1. Install the Live Server extension in Visual Studio Code.
  2. Right-click index.html and select "Open with Live Server".
  3. Use the pre-configured credentials: alex@sportsphere.edu / demo1234.

Examiner Talking Point: Explain how localStorage.setItem() and localStorage.getItem() are utilized to simulate persistent database state across page refreshes entirely within the client browser.
